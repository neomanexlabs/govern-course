# Cap and retire

Once a month, and whenever a file is at its cap. Every home for knowledge has a cap, written at its top: `AGENTS.md`, each standard, `review/failures.md`.

1. **Count.** For each rule and entry, count the reviews since the last count that cite it.
2. **Never followed.** A rule cited in review after review and never met: fix it so it can be followed, or retire it.
3. **Wrong.** A rule that states something false about the code: fix it.
4. **Never cited.** A rule no review cited: retire it, unless no change in that time touched what it guards. Say which.
5. **Cap.** A file at its cap takes a new rule only after one is retired.
